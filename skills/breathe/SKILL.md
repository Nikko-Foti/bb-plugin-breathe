name: breathe
description: Explain or configure Breathe, the standalone breathing wave above the BB composer.
---

A lavender pixel wave follows inhale, hold and exhale while the agent works. Classic (4/7/8), Even (4/4/4) and Unwind (4/0/6) presets and custom durations are available. Inhale/exhale accept 1–30 whole seconds; hold accepts 0–30, with zero skipping hold. BB supports pointer and keyboard ripples. Light mode uses an amethyst crest; dark mode uses moonlit lavender.

The scene appears only during connected active agent work, hides for pending user input or completion, and never changes prompts or agent behavior. Open Breathe settings through its composer label or the composer plus menu. Preview edits before Apply; Undo restores saved values. Replay only resets the preview. Closing discards unsaved edits. Hide dismisses the current turn.

Settings belong only to this plugin and are shared across BB threads. System reduced motion shows a stationary scene, and hidden/offscreen scenes pause. The plugin can run alongside the other standalone scene; enable either or both independently.

The separate Claude Code package exposes `/breathe` with its own host-managed settings and an explicit Still mode. There are no BB CLI commands, agent tools, network services or model calls.
